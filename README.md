# yandex-disk-api-autotests

## Запуск тестов
По умолчанию тесты запускаются в 3 потока 

```sh
./scripts/run_tests.sh
```
Можно указать другое количество потоков (например, 1)
```sh
./scripts/run_tests.sh 1
```
**Для тестов, которые завершились с ошибкой, производится повторный запуск (reruns=3)**

**После выполнения тестов разворачивается отчёт Allure**
